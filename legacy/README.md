# legacy

Seluruh fiturnya sudah dipindahkan ke paket `gamelokal`: workbench, riwayat versi, pengecekan tag, `.pak`, ekspor, impor terjemahan lama, dan penyedia libre/mymemory/claude. Satu perbedaan: glosarium untuk Claude sekarang berupa CSV (sama dengan `qa`), bukan JSON.

Skrip ini tidak dipakai oleh paket.
